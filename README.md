# Zepto Retail Data Analysis | Power BI Dashboard

## Project Overview
This project focuses on analysing Zepto retail product data to understand product categories, pricing, discounts, and stock availability. An interactive Power BI dashboard was created to present the data in a clear and useful format.

## Objectives
- Analyse product distribution across categories.
- Understand product pricing and discount patterns.
- Compare maximum retail prices with discounted selling prices.
- Analyse stock availability across categories.
- Identify products offering the highest discounts.

## Tools & Technologies
- **Power BI Desktop** – Data cleaning, visualisation and dashboard development.
- **MySQL Workbench** – Database creation and SQL data exploration.
- **CSV** – Dataset format.

## Dataset Description
The dataset contains 9 columns:

| Column | Description |
|---|---|
| Category | Product category |
| name | Product name |
| mrp | Maximum retail price |
| discountPercent | Discount percentage |
| availableQuantity | Available stock quantity |
| discountedSellingPrice | Discounted selling price |
| weightInGms | Product weight in grams |
| outOfStock | Stock availability status |
| quantity | Product quantity |
